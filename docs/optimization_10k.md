## 代码改动与复现

- 固定清单按指定回合数截取，修复设置 3 回合却执行 10 回合的问题。
- 专家回放后、策略场景初始化前重新设置 Python 和 NumPy 随机种子；这减少随机状态差异，但不保证物理引擎完全确定。
- checkpoint_sweep.py 串行评测、保存视频、核对回合种子和指令、汇总结果，支持跳过已完成模型。
- 新增 --episode-offset，避免验证重复使用筛选场景。
- optimization_pipeline.sh 的训练后评测默认关闭时间集成。

在配置好的本机上重新运行或恢复追加验证：

```bash
bash 02_代码材料/diagnostics/start_validation.sh
```

六模型筛选：

```bash
python3 02_代码材料/diagnostics/checkpoint_sweep.py   --output outputs/diagnostics/checkpoint_sweep_v2
```

脚本依赖本地 Conda 环境、RoboTwin、上游 LingBot 代码及推理服务的时间集成参数接口、模型权重和历史场景清单。仓库提供配置和实验补充材料，并非可独立运行的完整代码镜像。迁移机器时需调整路径；已上传的场景清单可用于重建脚本默认位置。已有输出目录会跳过已完成评测，重新实验应使用新目录。
